# Pastel Pocket

Mobile-first expense tracker inspired by the provided mockups.

## Features

- Pastel dashboard with overview, totals, savings, entries, and settings screens
- Add, edit, and delete expense entries
- Automatic local data saving with `localStorage`
- Offline-ready app shell with manifest and service worker
- Simple local server for testing on desktop or phone

## Run

```bash
node server.js
```

Then open `http://localhost:4173` on the same machine, or use one of the printed `Phone access` URLs from another device on the same network.
